# list

### Overview

List cluster PCI devices

### Command Parameters

```bash
--host-ids=string             Filter by host IDs; JSON array format required
--ids=string                  Filter by device IDs; JSON array format required
--name=string                 Filter by device name, example: eth5
--status=string               enum=['Offline', 'Normal']. Filter by device status. Values: Offline, Normal
--type=string                 enum=['iface', 'encryption']. Filter by device type. Values: iface (network card), encryption (encryption card)
--model=string                Filter by device model. Example: VMXNET3 Ethernet Controller, example: VMware
--mode=string                 enum=['vf', 'passthrough', 'pf', 'none']. Filter by device mode. Values: vf (virtual function), passthrough, pf (physical function), none (not configured)
--submodule=string            enum=['pf', 'vf', 'pci']. Submodule type to include in the list. Values: pf, vf, pci
--excludable-submodule=string enum=['pf', 'vf', 'pci']. Submodule type that cannot be included in the list. Values: pf, vf, pci
--enable=boolean              Whether to return only enabled devices
--use-cache=boolean           Whether to use cache (default uses cache when omitted; 0/false triggers real-time query)
--start=integer               Pagination start position (from 0, min 0); used with --limit, both must be provided together
--limit=integer               Page size (max 50); used with --start, both must be provided together
--keyword=string              Fuzzy match keyword for PCI devices
--sort=string                 enum=['status', 'type', 'slot', 'mode', 'relatedVMS']. Sort field (defaults to name). Values: status, type, slot, mode, relatedVMS
--direct=string               enum=['ASC', 'DESC']. Sort direction. Values: ASC (ascending), DESC (descending); used with --sort
```

### Usage Example

```bash
acli platform cluster pcie list
acli platform cluster pcie list --host-ids '["host-0050568ec35e"]' --type iface --status Normal
```
