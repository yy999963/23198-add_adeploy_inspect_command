# list

### 操作概述

查询集群 PCI 设备列表

### 命令参数

```bash
--host-ids=string             按主机ID过滤，需传JSON数组格式，示例：['host-0050568ec35e']
--ids=string                  按设备ID过滤，需传JSON数组格式，示例：['0000:1b:00.0']
--name=string                 按设备名称过滤，示例：eth5
--status=string               枚举=['Offline', 'Normal'] 按设备状态过滤，可选值：Offline（离线）、Normal（正常）
--type=string                 枚举=['iface', 'encryption'] 按设备类型过滤，可选值：iface（网卡）、encryption（加密卡）
--model=string                按设备型号过滤 VMXNET3 Ethernet Controller，示例：VMware
--mode=string                 枚举=['vf', 'passthrough', 'pf', 'none'] 按设备模式过滤，可选值：vf（虚拟功能）、passthrough（直通）、pf（物理功能）、none（未配置）
--submodule=string            枚举=['pf', 'vf', 'pci'] 指定加入列表的子模块类型，可选值：pf、vf、pci
--excludable-submodule=string 枚举=['pf', 'vf', 'pci'] 指定无法加入列表的子模块类型，可选值：pf、vf、pci
--enable=boolean              是否仅返回已启用的设备
--use-cache=boolean           是否使用缓存（不传默认使用缓存；传0/false则实时查询）
--start=integer               分页起始位置（从0开始，最小0）；与--limit配合使用，需同时传入
--limit=integer               分页每页数量（最大50）；与--start配合使用，需同时传入
--keyword=string              PCI设备模糊匹配关键字
--sort=string                 枚举=['status', 'type', 'slot', 'mode', 'relatedVMS'] 排序字段（默认按name排序），可选值：status、type、slot、mode、relatedVMS
--direct=string               枚举=['ASC', 'DESC'] 排序方向，可选值：ASC（升序）、DESC（降序）；需与--sort配合使用
```

### 使用示例

```bash
acli platform cluster pcie list
acli platform cluster pcie list --host-ids '["host-0050568ec35e"]' --type iface --status Normal
```
